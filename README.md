# EarthEcho

EarthEcho is an environmental awareness website developed as a group project for CSSD 1202 and CSSD 1161 at York University.

## About the Project

The website provides information and interactive resources related to environmental awareness and sustainability.

## Technologies

- HTML
- CSS
- Git/GitHub

## My Contribution

I contributed to the development and design of the website by working on movement, colours, and animations to improve the user experience. I also helped develop the Achievements & Badges and Eco Inspirations pages.
